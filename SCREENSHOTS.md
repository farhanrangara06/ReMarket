# ReMarket – Screenshot Checklist

Take these screenshots after running the project locally. Save them in a `screenshots/` folder for your journal and report.

---

## 1. Home Page
**What to show:** Hero section ("Buy Smart. Sell Easy. ReMarket."), popular categories, featured products, how-it-works section, and footer.

## 2. Registration Page
**What to show:** Registration form with fields (name, email, password, phone, city, profile image) and validation.

## 3. Login Page
**What to show:** Login form with email and password fields.

## 4. Products Page
**What to show:** Product grid with cards showing image, title, price, condition, location, and seller name.

## 5. Search and Filter
**What to show:** Search bar active with results, or filters panel open (category, condition, location, price range, sort).

## 6. Product Details
**What to show:** Full product page — image gallery, title, price, description, seller info, status, and action buttons.

## 7. Sell Product Form
**What to show:** Complete sell form with category, condition, price, location, and image upload.

## 8. Product Created
**What to show:** Success toast or newly created product visible on product details or my listings page.

## 9. User Dashboard
**What to show:** Dashboard with stat cards (listings, wishlist, requests) and quick action links.

## 10. My Listings
**What to show:** List of user's own products with edit, delete, and mark-as-sold options.

## 11. Purchase Request (Buyer)
**What to show:** Purchase request modal with message and optional offered price, or sent requests page.

## 12. Received Request (Seller)
**What to show:** Received requests page with accept/reject buttons on a pending request.

## 13. Accepted/Rejected Request
**What to show:** Request card showing "Accepted" or "Rejected" status badge.

## 14. Wishlist
**What to show:** Wishlist page with saved products and remove option.

## 15. Notifications
**What to show:** Notifications page or dropdown with unread indicators and notification messages.

## 16. Profile Page
**What to show:** Profile update form and change password section.

## 17. Admin Dashboard
**What to show:** Admin stats cards — total users, products, available, sold, pending requests.

## 18. Admin User Management
**What to show:** Users table with block/unblock actions and search.

## 19. Admin Product Management
**What to show:** Products table with status filter and remove action.

## 20. MongoDB Collections
**What to show:** MongoDB Compass or `mongosh` showing collections: users, products, purchaserequests, notifications, categories with sample documents.

## 21. VS Code Project Structure
**What to show:** VS Code explorer with `client/` and `server/` folder structure expanded.

## 22. GitHub Repository
**What to show:** GitHub repo page with README, commits, and project files visible.

---

## Tips

- Use consistent browser window size (1280×720 or full screen)
- Hide personal bookmarks bar for cleaner screenshots
- Take both desktop and mobile (responsive) screenshots if possible
- Label each screenshot file clearly: `01-home.png`, `02-register.png`, etc.
