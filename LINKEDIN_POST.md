🚀 **Excited to share my latest college project — ReMarket!**

ReMarket is a full-stack **used products marketplace** built with the **MERN stack** (MongoDB, Express.js, React, Node.js). It allows users to buy and sell pre-owned items locally — think of it as a campus-friendly alternative to OLX.

**What problem does it solve?**
Students and households often have usable items they no longer need. ReMarket makes it easy to list, discover, and connect with buyers — without complicated setup.

**Key Features:**
✅ User authentication with JWT  
✅ Product listing with image upload  
✅ Search, filter, sort & pagination  
✅ Wishlist  
✅ Purchase request workflow (send → accept/reject → complete)  
✅ In-app notifications  
✅ User dashboard with stats  
✅ Admin panel for platform management  
✅ Responsive UI with Tailwind CSS  

**Tech Stack:**
React · Vite · Node.js · Express · MongoDB · Mongoose · JWT · Multer · Axios · Tailwind CSS

**What I learned:**
- Building RESTful APIs with proper validation and error handling
- JWT-based authentication and role-based authorization
- MongoDB schema design with Mongoose
- Connecting React frontend to Express backend via Axios
- File upload handling with Multer
- Designing a complete purchase request workflow with notifications
